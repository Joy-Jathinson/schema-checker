# Schema Checker

A lightweight technical SEO tool designed to inspect structured data and help identify potential schema markup issues.

## What It Does

Schema Checker helps SEO professionals review structured data implementation and identify opportunities to improve markup quality.

## Key Features

- Inspect structured data on web pages
- Identify potential schema markup errors
- Highlight missing or incomplete properties
- Support structured data quality assurance
- Simplify technical SEO reviews

## Why I Built It

Manually reviewing structured data across websites can be time-consuming. I created Schema Checker to make schema inspection easier and support more efficient technical SEO workflows.

## Use Cases

- Technical SEO audits
- Ecommerce product schema reviews
- Article and organisation schema inspections
- Structured data implementation checks
